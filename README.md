# Slice YouTube Video

تطبيق Next.js كامل (بدون باك إند منفصل) لقص جزء محدد من أي فيديو يوتيوب وحفظه مباشرة على جهاز المستخدم كملف MP4.

## التشغيل محلياً
```bash
npm install
npm run dev
```

## النشر بـ Docker (Render / Railway / VPS)
المشروع يحتوي على `Dockerfile` جاهز يثبّت `FFmpeg` و `yt-dlp` مع Node.js 22.

### المتغيرات البيئية الاختيارية
- `MAX_HEIGHT`: أقصى دقة للفيديو المقصوص (مضبوطة افتراضياً في Docker على `720` لتقليل استهلاك الرامات).
- `YTDLP_COOKIES_BASE64`: (اختياري) ملف كوكيز يوتيوب مشفّر Base64 إذا طلب يوتيوب تأكيد الهوية على السيرفر.
